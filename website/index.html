Hands for your agent

Coding agents can read and write files, but they can't click. Ultron Hands is a skill for them: an MCP server that lets the agent see your screen, move the mouse, click, scroll and type. Anything that needs a person at the computer, you can now hand off.

# Claude Code
claude mcp add ultron-hands -- ultron-hands
# Codex
codex mcp add ultron-hands -- ultron-hands

Hands runs in the original Ultron today and comes to the Rust app in wave 4.

Ask for things like

  • “Turn on Discussions in this repo's GitHub settings.”
  • “Fill in this form with the details from invoice.pdf.”
  • “Find the export button in this app and save last month's report.”

How it works each step

  1. Look. The agent takes a screenshot, with the cursor marked by a red ring.
  2. Act. It clicks, types or scrolls, using exact control positions from the accessibility tree when the app exposes them.
  3. Check. It looks again and only moves on when the screen shows the step worked.

Ultron, the app

A flip clock that lives at the top of your screen and answers when you talk to it.

Prompt bar
Ctrl+Space opens it in the middle of the screen, Ctrl+Shift+Space beside your cursor.
Timers and focus time
Start a timer or stopwatch by asking. Every session is logged, so you can ask how much you worked this week.
Memory
Tell it facts and your own phrases once. It learns the plans that worked and takes corrections like “no, I meant…”.
Your choice of model
Claude Code, Codex, a local model through Ollama, or an API key from any provider. Different ones for different jobs.
Voice
Push to talk with Whisper running on your machine, or a live conversation with Gemini.
Abilities it writes itself
Ask for a tool it doesn't have and it builds one, run in a WebAssembly sandbox with only the permissions you grant.

You stay in charge

  • Your requests only. It acts on what you asked, never on instructions it reads on a screen or a web page.
  • One command stops it. A kill switch halts all control at once.
  • No passwords. It never types them, and what it types is never logged.
  • A record of everything. Every click and keystroke it makes is logged on your machine.

Build it with us

Ultron is MIT or Apache-2.0, written in Rust with a Tauri interface. Each piece of the rewrite is checked against the original app before it ships, and the open pieces are listed as issues.

git clone https://github.com/ultron-hq/ultron
cd ultron && cargo build --release
./target/release/ultron-rs --help
