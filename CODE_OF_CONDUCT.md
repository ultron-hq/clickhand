# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, welcome newcomers, and keep criticism about the code, not
the person. Harassment, insults and personal attacks are not tolerated in issues, pull requests,
discussions or any other project space.

Report unacceptable behavior privately to the maintainers through
[GitHub's report feature](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
or a private security advisory. Reports are handled confidentially, and maintainers may remove
content or ban participants who break these rules.
